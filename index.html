White Hat Write-Up

The visualization above uses ProPublica’s release of the civilian complaint records from New York City’s Civilian Complaint Review Board and the analysis is done using a row in the published allegation data because several allegation records can belong to the same complaint. Therefore, the visual above identifies the separate counts of unique complaints and officers.

Records from the data are grouped by the category of the allegation and the investigation outcome in the chart encoded by the different colored bars. Outcomes having different disciplinary recommendations are under “substantiated,” and the unsubstantiated and exonerated outcomes remain separate. Unrecognized/Missing outcomes are stored in an additional category instead of outright removed from the dataset. The percentage view helps divide each outcome count by total records within its same allegation category. The count view uses the same records, but starting from 0, so the information is presented uniformly.

Horizontal stacked bars help support the comparisons across the different outcome categories. Colors and exact percentages help display the information of the dataset in a clear manner. Percentage bars also are used to make the composition visible, while the count shows the differences in recorded volume that percentage bars may not be as noticeable. The dropdown table also is used to provide exact counts and rounded percentages from the ProPublic dataset.

This method likely introduces bias because officers without any substantiated allegations are excluded, so the outcomes may differ across the entire police department.

What changed—and what did not

  1. The combined category is split. Unsubstantiated findings are no longer presented as equivalent to exoneration.
  2. The denominator is corrected in the label. The large percentage describes allegation records, not officers.
  3. The headline stops implying innocence. Investigation uncertainty is made explicit.

The large percentage remains unchanged because it is still the sum of the same two outcome groups. Its meaning changes when the label and context are corrected.

Black-Hat Write-Up

The black hat visualization uses the same ProPublica data as the white hat visual but uses semantic aggregation, which combines unsubstantiated and exonerated outcomes, which are different, into a single category called “Cleared.” This grouping causes the lack of sufficient evidence to appear as equivalent to finding that the officer’s conduct complied with the department’s rules. Although the combined count is technically correct, the newly created category pushes a conclusion that the white hat does not agree with.

A second manipulation changes what the visualization appears to count. The “Officers Cleared” group represents a percentage from the allegation records, not a percentage of unique officers in the department. Because one officer can appear in multiple allegation records, the percentage of allegations shouldn’t be treated as the percentage of officers cleared. The headline also presents the outcomes as evidence of clearance rather than separating uncertainty from exoneration.

The combined category uses a bright teal color and a large summary statistic in the header, while the substantiated groups' outcomes appear in gray, which hides its significance. The percent axis, sample size, and source attribution make the display appear credible even though there is misleading grouping and labels.

At the bottom, the “Uncover Bias” button separates the combined outcomes and corrects the label to identify the allegation records rather than officers, making the results very similar to the white hat chart. The underlying counts remain unchanged, showing how accurate calculations can still cause misinterpretation when categories and labels suggest an unsupported conclusion.

Extra credit features

Uncover Bias: The “Uncover Bias” button transforms the black hat visualization into a more transparent presentation using the same records. It separates the misleading “Cleared” category into unsubstantiated and exonerated outcomes, corrects the allegation-versus-officer label, and replaces the reassuring headline with an explanation of investigation uncertainty. This feature extends the two required visualizations by allowing readers to inspect the manipulation directly rather than only reading about it.

Category Filtering: A category selector updates both charts, summary statistics, and the results table together. This allows the visual to be more interactive and users can dive deeper into specific variables more.

Percentage and Count Comparison: The white hat visualization switches between percentages and absolute counts using the same records. Percentage views reveal outcome composition, while counts expose differences in sample size that equally long percentage bars conceal. This demonstrates how the measurement can affect interpretation of a visual.

Results Table: An expandable table displays exact outcome counts, percentages, and category totals for the current selection. This allows the viewers of the page to see exact data that the visualizations are based off of.
